En una instalación nueva: `npm ci`, completar una copia privada de `.env.example`
como `.env.local` y ejecutar `npm run start:local`. En PowerShell usar `npm.cmd`.
No sobrescribir archivos del entorno actual. No capturar contraseñas ni tokens.
`BACKEND_API_URL` debe identificar el mismo backend para login y sesión.
